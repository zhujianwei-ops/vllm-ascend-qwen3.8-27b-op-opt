## 定位原则

等待累计来自多条 stream，其他 stream 可能仍在计算或传输；等待任务的总和不是可直接回收的时延。SDMA_SQE 累计同样不是整网新增耗时。

优先在 `task_time.csv` 用 `stream_id + task_id + task_start(us)` 查找长尾事件，再关联同一时刻的 producer、HCCL 和计算流。确认是否存在真实的计算空洞，再调整依赖或发起时机；不能删除必要的 Event/Notify 同步。

P50/P99 是同类任务耗时的分位数，使用线性插值；这与请求的 P99 ITL、TTFT 不同。设备任务时长与 op_statistic 的总和存在微小差异，来自导出的小数精度，应保留各自原始口径。
